# Connecting Plate

My pads didn't come with plates, so I made my own. They are not identical to AC, but they work. Notably, I did not include the bend on top (which adds strength), because I was more interested in cheaply obtaining these from an online vendor.

I ordered a pair from SendCutSend in October 2021 for $29 USD out of 11 gauge mild steel, without any coating because I planned to powdercoat them later. If you aren't doing that, I would recommend any protective coating to prevent rust or using stainless steel.
